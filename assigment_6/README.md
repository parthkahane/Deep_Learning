# Assignment 6 – Corn/Maize Leaf Disease Classification Using CNN

## Objective

The objective of this assignment is to implement a **Convolutional Neural Network (CNN)** for classification of Corn/Maize leaf diseases.

The assignment demonstrates the complete workflow of an image classification problem, including dataset loading, image preprocessing, visualization, CNN model construction, training, and model evaluation.

## Dataset

The **Corn/Maize Leaf Disease Dataset** is used for this assignment.

The dataset is downloaded from Kaggle using KaggleHub.

The images are resized to **128 × 128 pixels** and divided into:

* 80% Training Data
* 20% Validation Data

The dataset classes are automatically detected from the directory structure.

## Steps Performed

1. Downloaded the Corn/Maize Leaf Disease dataset using KaggleHub.
2. Imported the required TensorFlow, Keras, NumPy, Matplotlib, Seaborn, and Scikit-learn libraries.
3. Loaded the image dataset using `image_dataset_from_directory()`.
4. Split the dataset into training and validation datasets.
5. Resized the images to 128 × 128 pixels.
6. Visualized sample images from the training dataset.
7. Applied image pixel normalization using a Rescaling layer.
8. Optimized the input pipeline using caching, shuffling, and prefetching.
9. Built a Convolutional Neural Network.
10. Compiled the model using the Adam optimizer.
11. Trained the CNN for 10 epochs.
12. Plotted training and validation accuracy.
13. Plotted training and validation loss.
14. Generated predictions on the validation dataset.
15. Created a confusion matrix to analyze classification performance.
16. Generated a classification report containing precision, recall, and F1-score.

## CNN Architecture

The CNN consists of the following layers:

* Rescaling layer
* Convolutional layer with 32 filters
* Max Pooling layer
* Convolutional layer with 64 filters
* Max Pooling layer
* Convolutional layer with 128 filters
* Max Pooling layer
* Flatten layer
* Dense layer with 128 neurons
* Dropout layer with 50% dropout
* Output layer with softmax activation

The CNN architecture and preprocessing are implemented directly in the assignment notebook.

## Model Configuration

The model uses:

* **Image Size:** 128 × 128
* **Batch Size:** 32
* **Optimizer:** Adam
* **Learning Rate:** 0.0001
* **Loss Function:** Sparse Categorical Crossentropy
* **Epochs:** 10
* **Dropout:** 0.5

## Model Evaluation

The trained CNN is evaluated using several methods.

### 1. Training and Validation Accuracy

The accuracy graphs show how the classification accuracy changes during training for both the training and validation datasets.

### 2. Training and Validation Loss

The loss graphs show how the model's error changes during training and help identify possible overfitting or underfitting.

### 3. Confusion Matrix

A confusion matrix is generated by comparing the actual disease classes with the classes predicted by the CNN.

It helps identify which disease classes are correctly classified and which classes are confused with one another.

### 4. Classification Report

A classification report is generated containing:

* Precision
* Recall
* F1-score
* Support

These metrics provide a detailed evaluation of the classification performance for each disease class.
